# 角色系统开发默认提示词

当前规则系统：`{{system}}`
提示词版本：`{{promptProfileVersion}}`

## 目标

角色系统必须像电子游戏角色界面，而不是纸面字段搬运。角色创建、查看、编辑、升级、装备、资源、法术、状态、标签、存档和 AI 摘要使用同一份数据。

## 默认标准

1. 创建、查看、编辑复用同一套规则组件和数据模型。
2. 自动选项来自规则书数据；属性、加值、熟练、装备、法术、资源、派生值互相联动并显示来源。
3. 玩家常用按钮放在高频区域，低频说明进入分页、标签或浮窗。
4. 背包是数量化库存；物品是否可装备由数据决定；购买、价格、重量和装备状态可追踪。
5. 标签使用全局统一系统，浮窗显示完整定义和来源，不能显示对象泄漏或错误链接。
6. 保存前保留 GM 历史版本，支持对比和恢复。

## 验收

用真实角色数据创建或修改一次，验证派生值、来源、保存恢复、浮窗、权限和 AI 摘要。

补充标准：规则资料默认使用官方扩展，第三方、自制、同人内容必须有显式开关。职业成长、子职业、专长、法术与装备必须按来源管理；来源变化时先撤销旧效果、物品和法术，再写入新结果。开卡装备使用背包列表与物品名自动匹配，不使用大面积芯片墙；编辑现行角色卡时添加背包条目不自动扣金币。背景属性加值在属性页配置并显示具体属性、加值、前后数值与来源。随机属性候选固定预留 5 条横向行。职业属性提升使用可拖动点数方块分配，支持 +2/+1 与三项 +1，允许取消后重新拖放。
