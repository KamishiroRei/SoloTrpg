# SoloTrpg

AI驱动的通用单人TRPG跑团平台。

因为自己的团鸽了好像一个月于是忍不住捣鼓了这么个东西。接入AI后让AI自己部署一套TRPG基类。暂时没考虑联机。

## 快速开始

双击 `start.bat` 即可。或手动：

```bash
cd server && npm install && node server.js
```

浏览器打开 `http://localhost:3000` 或直接打开 `start.html`（基础功能）。

## 功能

- 地图画布：方形网格、角色标记、法术范围
- 通用骰子：d4~d100，表达式 2d6+3、4d6k3、优劣势
- AI游戏主持：多模型，严格规则，不确定时翻查规则书
- 极小上下文：只注入核心提示+压缩状态+最新对话
- 房间联机：房主创建房间码→朋友打开链接自动加入
- 检定工具：GM发起检定→玩家逐条掷骰→批量发送AI
- 动态角色卡：AI读取规则书后自动生成字段配置
- 系统自动存档：对话自动记录，不消耗AI token
