# SoloTrpg（TrpgRecode）

为了方便自己跑团，用 AI 模仿 opencode 写出来的小玩具，让 AI 自己去解析规则书，生成配套的自动工具和带团。

## 它做什么

- **AI 解析规则书**：上传 PDF/CHM/TXT/MD 规则书后，AI 自动通读全书，整理为可查询的规则库（compressed/ 产物），并生成配套插件（角色卡、职业指南、怪物图鉴、法术查询等）。
- **AI 带团**：AI 作为 GM 按规则判定、推进剧情、管理数据（HP/资源/物品/状态精确更新），以结构化标记输出判定与状态，前端渲染为精美界面。
- **AI 自主迭代**：内置"系统频道"，AI 能读取、修改、创建插件与宿主代码，按唯一验收标准（最佳玩家游戏体验）持续优化自己。

## 快速开始

```text
SoloTrpg.exe
```

**exe 是正式入口**：双击即启动（内嵌 Node 运行时，无需安装 Node.js），打开原生游戏窗口：
- window.open 的新窗口由宿主接管为**原生独立窗口**（带边框、可拖动、与主窗口分离）
- 关闭窗口 = 停止服务；F5 刷新保持当前界面（不回到开始界面）
- 首次运行自动解压运行环境到 `%LOCALAPPDATA%\SoloTrpg\bin`

首次使用：在开始界面点击「📤 上传规则书」，上传规则书后 AI 会自动解析；之后选择规则书 → 冒险 → 进入。

> 网页版调试：`start.bat`（需要本机 Node.js，前台窗口显示实时日志，浏览器打开 http://127.0.0.1:3000）——仅供开发/排错，日常使用请用 exe。

## 核心概念

- **规则书-冒险-频道** 三级会话管理：规则书是"游戏"，冒险是"存档"，频道（剧情/战斗/系统）是会话；删除频道/归档冒险均不影响本地文件，可随时查阅恢复。
- **开始界面**：选择规则书 → 选择冒险（或「继续上次」一键进入），像游戏主菜单。
- **主菜单侧边栏**（☰）：返回开始界面、切换规则书、冒险管理。

## 开发

- 唯一后端：`server/server.js`
- `SoloTrpg.exe`：**正式入口**（WebView2 原生窗口，内嵌 Node 运行时），由 `build-exe.bat` 构建
- `start.bat`：调试备用（需要本机 Node.js，前台日志窗口 + 浏览器）
- 日志：`Logs/`（latest.log 为首选诊断文件）
- 代码修改后重新构建 exe 才生效（`build-exe.bat`）；前端修改也可用 `start.bat` 网页版直接验证

## AI 配置

设置 → AI 中可选 GPT 或自定义 API（OpenAI Chat Completions 兼容，如 DeepSeek）。`config.json` 保存配置，**不会被上传**（见 .gitignore）。

## 注意

- 本项目是个人跑团玩具，规则书数据（Ruler/）为本地内容，按需使用。
- AI Key 等敏感配置只存在于本地 `config.json`，不进入版本库。
