# SoloTrpg

AI驱动的通用单人TRPG跑团平台。双击即玩。

因为自己的团鸽了好像一个月于是忍不住捣鼓了这么个东西。

## 启动

双击 `SoloTrpg.exe`。浏览器会自动打开。

首次运行自动创建 Ruler/ Module/ Archive/ 目录。

## 目录

```
SoloTrpg.exe        # 游戏启动程序
app/                # 游戏界面
  ├── index.html
  ├── css/
  └── js/
server/             # 后端源码
Ruler/              # 规则书（AI自动创建）
Module/             # 模组
Archive/            # 会话存档
docs/               # 文档
```
