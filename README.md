# SoloTrpg

AI驱动的通用单人TRPG跑团平台。

因为自己的团鸽了好像一个月于是忍不住捣鼓了这么个东西。接入AI后让AI自己部署一套TRPG基类。暂时没考虑联机。

## 功能

- 地图画布：方形网格、平移缩放、角色标记、法术范围显示
- 通用骰子：d4~d100，表达式 `2d6+3`、`4d6k3`、优劣势
- AI游戏主持：多模型支持，严格遵守规则，不确定时主动翻查规则书
- 极小化上下文：每次只注入核心提示+压缩状态+最新对话，规则书不注入
- 系统自动存档：对话自动记录到 `Archive/`，不消耗AI token
- 规则书任务区：AI启动时自动扫描接管。上传PDF/CHM → 压缩为标准查表格式
- 模组目录：剧本文字+资源图片，AI按需搜索
- 动态角色卡：AI读取规则书后自动生成字段配置

## 快速开始

```bash
npm install
node server.js
# 浏览器访问 http://localhost:3000
```

不启动后端可使用基础功能（地图、骰子、手动管理）。

## 目录结构

```
Ruler/{系统名}/           # 规则书任务区
├── SKILL.md             # AI快速接手摘要
├── compressed/          # 压缩查表格式
├── source/              # 原始文本存档
├── 模组/                # 剧本+资源
└── 存档/                # 按冒险区分

Module/                  # 独立模组
Archive/                 # 全局存档（系统自动记录）
```

## 上下文机制

每次AI调用只注入：
1. 核心提示（~300字）：GM准则+查询规则方式
2. 一行式游戏状态
3. 最近2-3轮对话

AI需要规则时回复 `[[search:关键词]]`，系统拦截并搜索规则书，结果注入后AI继续。

## 技术栈

前端：HTML/CSS/JS（无框架）  
后端：Node.js + Express  
AI：OpenAI兼容API
