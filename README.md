# SoloTrpg

AI驱动的通用单人TRPG跑团平台。双击即玩。

## 启动

双击 `SoloTrpg.exe`。首次运行自动创建 Ruler/ Module/ Archive/ 目录。

需要联机时，启动完整服务端：`cd server && npm install && node server.js`

## 目录

```
SoloTrpg.exe    # 游戏（17MB，独立exe）
app/            # 界面文件
server/         # 联机服务端（可选）
Ruler/          # 规则书
Module/         # 模组
Archive/        # 存档
```
